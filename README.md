# Personal Mini-Toolkit (Week 8 Final Project)

## Project Overview
This project is a console-based, menu-driven **Personal Mini-Toolkit** built in Python. It brings together all core concepts learned throughout the course—including variables, user input/output, conditionals, loops, dynamic lists, and robust error handling—into one cohesive, friendly program.

## Included Tools
1. **To-Do List Manager:** Allows users to dynamically view, add, and remove tasks from an active list during runtime.
2. **Simple Calculator:** Performs basic arithmetic operations (+, -, *, /) on two numbers with built-in zero-division and invalid input protection.
3. **Number-Guessing Game:** Challenges the user to guess a randomly generated secret number between 1 and 20 with a limited number of attempts and helpful higher/lower hints.
